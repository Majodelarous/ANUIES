# Lenguaje ubicuo

| Término | Significado |
|---|---|
| Persona | Persona adulta mayor que recibe las llamadas |
| Trato | Cómo le gusta que le digan (por ejemplo, "doña Carmen") |
| Familiar | Persona de la familia o de apoyo que ve el panel y recibe alertas |
| Contacto de emergencia | Familiar que recibe las alertas de crisis |
| Llamada | Sesión de conversación por teléfono o navegador |
| Recuerdo | Fragmento de la historia de vida que la persona cuenta y acepta guardar |
| Actividad | Algo que se hace dentro de la llamada: reminiscencia o juego de memoria |
| Juego de memoria | Refranes para completar, adivinanzas o lista de palabras |
| Pregunta de bienestar | Pregunta inspirada en la GDS-15 o en la escala breve de soledad |
| Respuesta de bienestar | Respuesta sí o no (o frecuencia) a una pregunta de bienestar |
| Señal de bienestar | Semáforo y tendencia calculados con las respuestas recientes; no es diagnóstico |
| Recordatorio | Aviso de medicina, cita o hábito, con hora |
| Mensaje familiar | Mensaje que un familiar deja para que la asistente lo entregue |
| Alerta | Aviso a la familia: informativo, de atención o de crisis |

## Contextos

| Contexto | Responsabilidad |
|---|---|
| Conversación | Instrucciones, voz, herramientas y canal de la llamada |
| Memoria de vida | Guardar y recuperar recuerdos |
| Bienestar | Preguntas, respuestas y señal de bienestar |
| Cuidado | Recordatorios, mensajes familiares y alertas |
| Familia | Panel y notificaciones (pendiente) |
